# Spotify Global Weekly Top 50

This file is a fixed snapshot of the first 200 entries in Spotify's Global Weekly
chart for the week dated August 27, 2026. The course team retrieved the values
from Kworb's republished chart page on August 29, 2026. Kworb is a third-party
chart-tracking website, not Spotify.

Source retrieved: <https://kworb.net/spotify/country/global_weekly.html>

Spotify is the underlying chart provider. Spotify states that its chart stream
counts are generated using a formula that filters for chart eligibility, so
`streams` should not be interpreted as every raw Spotify play. See Spotify's
chart documentation: <https://support.spotify.com/ee-en/artists/article/understanding-spotify-charts/>.

The `previous_rank_change` column records the change from the preceding weekly
chart: `+` indicates an improvement, `-` indicates a decline, `=` indicates no
change, and `NEW` or `RE` can appear in a full chart extract. `streams` is the
number of global streams during this chart week.

This course snapshot should be used as-is so all students obtain reproducible
results; it is not intended to update automatically or serve as an audited
measure of all Spotify listening.
