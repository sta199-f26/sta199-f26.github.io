# Spotify Global Weekly chart data

This directory contains a fixed snapshot of the first 200 songs on Spotify's
Global Weekly chart for the week dated August 27, 2026. Each row in the chart
data represents one song.

Spotify releases a new chart each week. The chart data were retrieved on
August 29, 2026, from [Kworb.net's republished Spotify Global Weekly
chart](https://kworb.net/spotify/country/global_weekly.html).

## Files

- `spotify-global-weekly-2026-08-27.csv`: Chart data for the 200 songs.
- `spotify-artist-genres.csv`: A broad genre classification for each credited
  artist, intended to be joined to the chart data by `artist`.

## Chart variables

- `rank`: Position on the chart, where 1 is the highest position.
- `previous_rank_change`: Change in position from the previous weekly chart.
  A `+` indicates that a song moved up the chart, a `-` indicates that it moved
  down, and `=` indicates no change. `NEW` or `RE` can appear in a full chart
  extract.
- `artist`: Credited artist or artists.
- `song`: Song title.
- `weeks_on_chart`: Number of consecutive weeks the song has appeared on the
  chart.
- `peak_rank`: Best position the song has reached during its current chart run.
- `streams`: Number of global streams during the chart week.

## Artist genres

The `artist_genre` labels describe the credited artist's general musical style,
not necessarily the genre of every individual song. Artists and songs can
belong to more than one genre. The genre labels were generated by ChatGPT 5.6
Terra Medium on August 31, 2026.

## Notes

Spotify states that its chart stream counts are generated using a formula that
filters for chart eligibility. Therefore, `streams` should not be interpreted
as every raw Spotify play. See [Spotify's chart
documentation](https://support.spotify.com/ee-en/artists/article/understanding-spotify-charts/)
for details.
